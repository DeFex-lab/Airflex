# Contract Reference

AirFlex's on-chain logic is written in Rust using the [Soroban SDK](https://developers.stellar.org/docs/build/smart-contracts)
and deployed to the Stellar network. This section documents the public
functions of every contract in `contracts/`.

<Callout type="info">
  The **Escrow** contract page below is generated automatically from the
  `///` doc comments in [`contracts/escrow/src/lib.rs`](https://github.com/arflexx/Airflex/blob/main/contracts/escrow/src/lib.rs)
  by `scripts/generate-contract-reference.mjs`. Editing those comments and
  re-running `npm run generate:contracts` keeps this page current — see
  [Contributing](/contributing#regenerating-generated-docs).
</Callout>

sources land under `contracts/marketplace/` and `contracts/token/` with
documented (`///`) public functions, the generator will pick them up on the
next `npm run generate:contracts` run automatically, no page rewiring needed.
